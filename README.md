# Cybercraft Control Chip
[Download](https://github.com/vata-ot-nata/cybercraft-control-chip/releases/latest)

Cybercraft Implants is a plugin from the CyberCraft paper-plugin series. It adds a mind-control chip.
To insert a chip into a victim, right-click on them. To begin controlling them, right-click again.

## Installation

1. Install [ControlPlayer](https://www.spigotmc.org/resources/controlplayer-1-8-8-1-21-10.102987/) on your server
2. [Download the latest controlChip.jar](https://github.com/vata-ot-nata/cybercraft-implants/releases/latest) and place it in your `plugins` folder
3. Restart the server
4. Use a command below to get a control chip.

## Commands

To get a control chip, use this command:  
`/give @p minecraft:stone_button[custom_name='{"text":"Control Chip","color":"dark_red","italic":false}']`
